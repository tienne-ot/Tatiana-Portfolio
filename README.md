# Tatiana's Student Portfolio

Welcome to my personal student portfolio! This website was developed as part of my COS 106 practical project at Miva Open University.

## About the Project

The website showcases my educational background, interests, technical skills and projects as a Computer Science student.

## Features

- Home page with personal introduction and biography.
- About Me page with educational background and career aspirations.
- Projects page showcasing three projects.
- Interactive Academic Planner for adding, completing and deleting tasks.
- Contact page with JavaScript form validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript
